# 学習フィード（本番用ファイル一式）

スクロールで一問一答が進む、スマホ向け学習フィード。アカウント不要・完全無料・個人情報取得なし。
学習記録は利用者の端末内（LocalStorage）にのみ保存されます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（ヘッダー、教科タブ、進捗、フィード、自己判定フッター、設定・結果モーダル、解説シート） |
| `style.css` | デザインとレイアウト。高さの実測固定・フッター保護・セーフエリア対応を含む |
| `script.js` | 本体ロジック（出題、自己判定、再出題、保存、計測フック）。**計測IDを貼る場所もこのファイルの先頭** |
| `questions.json` | 問題データ（現在40問：英単語20＋社会20）。このファイルだけ編集すれば問題を増やせる |
| `README.md` | このファイル |

## 公開手順（GitHub ＋ Vercel の例）

1. GitHub で新しいリポジトリを作成し、この4ファイル（`index.html` / `style.css` / `script.js` / `questions.json`）をアップロードする
2. Vercel で「Add New → Project」からそのリポジトリを Import する
3. Framework Preset は「Other」のまま、Build / Output の設定は空で Deploy する（静的サイトなのでビルド不要）
4. 発行された URL を開き、スマホ実機で動作を確認する

※ `questions.json` は `fetch` で読み込むため、`file://` で直接開くと動きません。Vercel 等の https 環境（またはローカルの簡易サーバー）で開いてください。

## 計測（Google Analytics 4・匿名）の始め方

アプリ側には計測の仕組みが組み込み済みです。IDを1箇所に貼るだけで、以下が GA4 のレポートで見られるようになります。

- 訪問者数・再訪（継続率）：標準レポート＋ `session_start` イベントの `returning` パラメータ
- 解答された問題数：`judge` イベントの件数
- 10問区切りへの到達数：`chunk_reached` イベントの件数
- その他：`reveal`（答え表示）、`weak_toggle`（苦手マーク）

手順：

1. [Google Analytics](https://analytics.google.com/) でアカウントとプロパティを作成する（プロパティの対象は「ウェブ」、サイト名と本番URLを入力）
2. 発行される **測定ID（`G-` から始まる文字列）** をコピーする
3. `script.js` の先頭にある `const GA_MEASUREMENT_ID = '';` の `''` の中に測定IDを貼る
4. その状態で再デプロイする（GitHub に push すれば Vercel が自動で再デプロイ）

IDが空の間は計測されません。個人を特定する情報は送信しません（IP匿名化を有効化済み）。

## 問題の追加方法（questions.json）

1問 = 1オブジェクト。配列の末尾に追記するだけです。検品済みの問題を50問単位で足していく想定です。

```json
{
  "id": "eng-021",
  "subject": "english",
  "question": "important",
  "answer": "重要な、大切な",
  "explanation": "This is an important test.（これは大切なテストです）「大事な」と言いたい場面でよく使う。"
}
```

- `id`：重複しない一意の文字列。英単語は `eng-` ＋3桁、社会は `soc-` ＋3桁の連番
- `subject`：`"english"`（英単語）か `"social"`（社会）
- `question`：英単語は単語そのもの、社会は問題文
- `answer`：タップで表示される答え（短く）
- `explanation`：解説シートに出る詳しい解説（2〜3行、例文つき推奨）

編集後は JSON の文法エラー（カンマの過不足など）に注意してください。Vercel に上げ直せば即反映されます。

## 仕様メモ

- ジェスチャ：縦スワイプ＝次の問題／タップ＝答え表示／右側ボタン＝解説・苦手マーク／判定後の自動移動なし
- 自己判定（覚えてた・あいまい・ダメだった）に応じて再出題。間隔は設定で変更可（早め＝約3・6問後／ふつう＝約5・10問後／遅め＝約8・15問後）。再出題は最大3回まで
- 10問ごとに小結果を表示。判定しないまま進んだ問題はキューの最後に戻る
- 保存先は LocalStorage のみ。履歴・キャッシュ削除でリセットされる旨は、初回バー・設定・結果画面に明示済み
